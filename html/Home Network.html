This home network is segmented into three VLANs with separate SSIDs: Main, Guest, and IoT. The network is organized across multiple floors to provide optimal coverage.

On the main floor, the internet comes in through the ISP router in bridge mode, which connects to an OPNsense router. The OPNsense router then feeds a Layer 2 POE switch, which distributes connections to both wired devices and access points.

Connected to the switch:

  • Four desktops
  • One access point on the main floor
  • One access point upstairs
  • One access point downstairs

All access points operate in mesh mode, ensuring seamless wireless coverage throughout the home.
